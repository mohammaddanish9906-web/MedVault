# 🏥 MedVault

MedVault is an AI-powered medical learning platform built for MBBS students.

## Features

- 📚 Subject-wise Notes
- ❓ MCQs
- 📄 Previous Year Papers
- 🤖 MedGuide AI
- 🔍 Smart Search
- ⭐ Bookmarks
- 📈 Study Progress
- 👨‍💼 Admin Panel

## Technology

- Flutter
- Firebase
- Firestore
- Firebase Authentication
- GitHub
